## 第三轮：行间距根因修复 + 「相册监控」改版 + 历史图片显示修复

### 1. 转发设置行间距 ≠ 列间距（终于找到真根因）
- 用户发了截图：红框=行间隙（很大 ~34px），蓝框=列间隙（16px 正常）。
- **真根因**：全局 `.card { margin-bottom: 18px }`！在 `.fwd-grid` 网格内，margin 与 gap **叠加**：视觉行间距 = 16(gap) + 18(margin) = 34px，而列方向没有 margin = 16px。上一轮我改 row-gap/column-gap 都为 16px 根本没触及这个 margin，所以用户看新版仍不一致。
- 修复：`#view-forward .card { margin-bottom: 0 }`。同时精简「轮询间隔」的长说明（3 行→2 行）、压缩 `.sub` 间距，整页一屏。
- **重要教训：CSS 网格/弹性布局中，子项自带的 margin 会与 gap 叠加**。排查间距问题时必须检查子项自身的 margin，而不只是容器 gap。

### 2. 视频/相册 → 「相册监控」
- 用户实测：相册（图片）正常下载 ✔，视频无法下载 ✘ → 要求**删除视频功能**、模块改名「相册监控」、目录不再分 album/video、下载任务由每日定时改为**监控间隔**。

- 排查：DB 中 664/1363 条有 images 路径、data/images 有 977 个文件 → **下载和存储都正常**。
