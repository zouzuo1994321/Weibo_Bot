已记录账户（0/5）

自动续期 Cookie（临近失效自动滑动延长） 手动或自动（每 5 分钟）检测：登录态 + 真实抓取 + 转发能力

状态说明：正常=能登录、能抓到微博、能转发；Cookie失效=登录态过期，需删除该账户后重新登录；被风控=请求被微博限流，请调大轮询间隔；网络异常=本机网络或接口超时。Cookie 有效期列由 Cookie 中的 ALF/SSOLoginState 时间戳预测「若不再活动，登录态何时失效」，临近（≤7 天）会标黄。自动续期开启后，软件会在每次成功请求时滑动延长 Cookie，并在临近失效时自动续期，无需频繁重登（亦可点「续期」手动触发）。

转发设置

核心策略：每轮自动轮询会抓取所有监控对象的最新微博，若本轮存在新微博，则从中随机挑选一条进行转发。本次迭代新增 AI 三层去重（采样 / 历史库 / 结构随机化）与 人格安全条款（本地大模型路线下生效）。

轮询间隔

实际间隔在设定值 ±15% 内随机抖动（30 分钟 → 约 25.5–34.5 分钟），转发也在「设定间隔 ±15%」内随机延后（至多 4.5 分钟），避免固定节奏被识别为机器人。
