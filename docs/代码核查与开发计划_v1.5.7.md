## 三、缺陷清单

### P0 · 已在 v1.5.7 修复（7 项）

| 编号 | 缺陷 | 影响 | 修法 |
|---|---|---|---|
| BUG-1 | 授权有效期读**明文** `license.json.exp`，且 `exp==0` 视为永久 | 把该字段改成 0 即可永久授权，签名形同虚设 | 只认 HMAC 校验过的密钥体内 exp |
| BUG-2 | `model_manager.load_model()` 里 `model_path=_mp`（`_mp` 是下载函数的局部变量） | 选 local_gguf 引擎**必然** NameError，用户只看到"模型加载失败" | 改调 `model_path()`；另补缺失的 `debug` 导入 |
| BUG-3 | `weibo_client` 续期成功分支调用未导入的 `info()` | 会话真续期成功时抛 NameError，抓取中断且日志无线索 | 补导入 |
| BUG-4 | `logger._fh_lock` 是普通 `Lock`，而 `_get_fh → _rotate_if_needed → _close_fh` 重入同一把锁 | 日志超过 8MB 轮转时写入线程**死锁**（日志停更、退出卡住）。本机 app.log 仅 27KB 故未触发 | 改 `RLock` |
| BUG-5 | `_PRESERVE_EXT` 缺 `.gguf`；`splitext("history.db-wal")` 得 `.db-wal`，按扩展名匹配永远对不上 | 「清理缓存」会删掉 1GB 模型；**更严重**的是会删活库的 `-wal/-shm`（未落盘事务直接丢） | 补 `.gguf`，旁挂文件改后缀匹配 |
| BUG-6 | `delete_custom_persona` 成功路径没有 `return` | 桥接返回 None → 前端判 `r.ok` 为假，删成功却弹"删除失败" | 补返回值 |
| BUG-7 | CSS `var(--card)` 不存在（主题只有 `--bg-card`）；`paths.MAJOR_VERSION` 写死 `v1.3.2`、桥接兜底 internal 写死 `2609040001` | 首启向导整块透明浮在遮罩上；版本号从 v1.4.x 起长期对不上 | 改 `--bg-card`；版本号统一以 `version.py`/`version.json` 为单一来源 |

### P0 · 待修（安全加固，建议 v1.5.8 第一件事）

| 编号 | 缺陷 | 实证 | 影响 |
|---|---|---|---|
| SEC-1 | 桥接方法无路径白名单：`load_image_base64` / `load_media_base64` 接受任意磁盘路径 | 传 `C:\Windows\win.ini` → `ok:True`，内容被 base64 返回 | 前端任意脚本（含被注入了的微博内容回显路径）可读全盘文件 |
| SEC-2 | `open_path` 不做扩展名限制，直接交给系统执行 | 传 `C:\Windows\System32\calc.exe` → `ok:True`，计算器被**真的启动** | 等价于任意程序执行入口 |

**建议修法**（一次做完，约 0.5 天）：

```python
_ALLOW_ROOTS = (DATA_DIR, get_media_dir(), get_image_dir(), get_history_dir(), get_models_dir())

def _safe_path(self, p, must_exist=True):
    """把外部传入的路径钳制在数据目录之内，越界直接拒绝。"""
    if not p or not isinstance(p, str):
        return None
    ap = os.path.abspath(os.path.expanduser(p))
    for root in _ALLOW_ROOTS:
        try:
            if os.path.commonpath([ap, os.path.abspath(root)]) == os.path.abspath(root):
                return ap
        except ValueError:      # 跨盘符
            continue
    return None
```
- 读图 / 读媒资 / 缩略图 / 打开所在文件夹 全部先过 `_safe_path`；
- `open_path` 再叠一层扩展名白名单（只放行 目录 + 图片/视频/文档/压缩包），`.exe/.bat/.cmd/.ps1/.vbs/.js/.msi/.scr/.com` 一律拒绝并记日志。

### P1 · 技术债（影响可维护性 / 排障，不影响当前功能）
